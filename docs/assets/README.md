| File | Purpose | Recommended |
|------|---------|-------------|
| `screenshot-header.png` | Cyberdeck startup banner | 1400px wide, full boot screen |

Tips:

- Capture in a truecolor terminal with a Nerd Font for accurate rendering.
- Use a tool like [`asciinema`](https://asciinema.org) + [`agg`](https://github.com/asciinema/agg) to export GIFs if you want animated demos.
- Keep files under ~500KB; compress with `pngquant` or export as WebP.
- Alt text is already set in the README for accessibility — update it if the visuals change.
